SELISIH is an original spot-the-difference game: three hand-drawn night scenes (a lantern market, a dusk cat garden, a star pier), 21 differences to find against the clock, with hints, scoring, synthesized sounds, and keyboard + mouse play — all offline from static files.

## Run it

```sh
node serve.ts
```

Then open http://localhost:8080/game/index.html in a desktop browser.
